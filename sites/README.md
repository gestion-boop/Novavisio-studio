# Mini-sites d'information

Chaque dossier est un site statique hébergé dans son propre projet Vercel (Root Directory = le dossier),
puis ouvert dans NovaVisio via un point « Lien web » en mode « Intégré ».
Paramètres d'URL compris : `?langs=fr,en,es` (langues proposées) et `?lang=en` (langue de départ).

- `wills-hotel/` — Will's Hôtel, Narbonne (textes et photos issus du site de l'hôtel).
